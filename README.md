## 📌 프로젝트 개요
* **개발 기간:** 2026.07 ~ 2026.08 (1개월, 개인 작품)
* **팀 구성:** 1인 개발
* **장르:** 2D 아케이드 퍼즐 게임

## 🚀 기술적 도전 및 해결 과정 (Key Challenges)

### 1. Photon Fusion 기반 멀티플레이 시스템 구현
- **문제:** 여러 플레이어가 동일한 게임 세션에 접속하고, 각 플레이어의 상태와 게임 오브젝트를 일관되게 관리해야 했습니다.
- **해결:** `NetworkRunner`와 `NetworkObject`를 활용해 네트워크 세션을 구성하고, 플레이어 접속 시 네트워크 오브젝트를 생성하도록 구현했습니다.
- **결과:** 멀티플레이 환경에서 플레이어를 생성하고 관리할 수 있는 기반을 마련했습니다.

### 2. 플레이어 생성 및 게임 오브젝트 관리
- **문제:** 플레이어가 접속하거나 퇴장할 때 오브젝트가 중복 생성되거나 기존 플레이어 정보와 불일치하지 않도록 관리할 필요가 있었습니다.
- **해결:** `GameManager`를 중심으로 플레이어 오브젝트와 스폰 위치를 관리하고, 플레이어별 생성 상태 및 색상 등의 정보를 연결했습니다.
- **결과:** 플레이어 접속 및 퇴장에 따른 오브젝트 관리 구조를 구성하고, 멀티플레이 환경에서 발생할 수 있는 상태 관리 문제를 다뤘습니다.

### 3. 호스트 변경 및 재접속 처리
- **문제:** 호스트가 퇴장하면 남아 있는 플레이어가 호스트 역할을 이어받아야 하며, 기존 플레이어가 다시 접속했을 때에도 게임 진행 상태와 씬 전환이 정상적으로 처리되어야 했습니다.
- **해결:** Host Migration과 Runner 초기화 및 종료 흐름을 검토하고, 호스트 변경 이후의 플레이어 관리와 재접속 시 씬 전환 문제를 확인했습니다.
- **개선 방향:** 호스트 변경 전후의 네트워크 세션 상태와 씬 관리 책임을 명확히 분리하고, 다양한 접속·퇴장 순서에서 안정적으로 동작하도록 보완할 계획입니다.

## 🛠️ Tech Stack

- **Engine:** Unity 6 (6000.0.33f1)
- **Language:** C#
- **Networking:** Photon Fusion
- **Tools:** Visual Studio, Git
- **Key Skills:** 멀티플레이 네트워크 프로그래밍, 네트워크 오브젝트 관리, 플레이어 생명주기 처리, 씬 전환 및 세션 관리

## 💡 프로젝트를 통해 배운 점 (Reflection)

Photon Fusion을 활용해 멀티플레이 게임의 접속과 플레이어 생성, 오브젝트 관리 구조를 구현했습니다. 특히 호스트 퇴장과 재접속 상황을 테스트하면서, 멀티플레이에서는 단순히 오브젝트를 생성하는 것뿐 아니라 네트워크 세션과 씬의 생명주기를 함께 고려해야 한다는 점을 배웠습니다.

또한 호스트 변경과 재접속 과정에서 발생하는 문제를 추적하며, 네트워크 상태와 게임 로직 사이의 의존성을 줄이고 예외 상황을 고려한 구조를 설계하는 것이 중요하다는 점을 확인했습니다.
